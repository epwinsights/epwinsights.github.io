Weather File & Guide
Load EPW: Drag & drop a file, browse your device, or pick directly from the interactive map.
Compare: Once your primary file loads, a second drop zone opens automatically.
Filter Data: Use the dynamic sidebar controls within each analysis tab to customize charts.
Edit Info: Click the edit icon in Location Summary to customize station names for reports.
Export: Use the camera icon on any chart to download a publication-ready PNG.
